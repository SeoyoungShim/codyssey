Ubuntu Docker Container 실습

1. Ubuntu 컨테이너 실행: docker run -it --rm ubuntu bash
2. 현재 위치 확인: pwd
3. 디렉터리 목록 확인: ls
4. 운영체제 정보 확인: cat /etc/os-release
5. 파일 생성: echo Hello, Ubuntu Docker! > hello.txt
6. 파일 내용 확인: cat hello.txt
7. 파일 권한 확인: ls -l hello.txt
8. 파일 권한 변경: chmod 600 hello.txt
9. 파일 상세 정보 확인: stat hello.txt
10. 파일 이름 변경: mv hello.txt ubuntu-note.txt
11. 파일 삭제: rm ubuntu-note.txt
12. 컨테이너 종료: exit

결과: 모든 명령어 정상 실행
